# Validation / Validare — v1.0.1

## English

The Release test suite passes **75 automated tests** covering threshold/hysteresis, charging, missing/stale data, persistence, state migration, protocol parsing, invalid responses, timeouts, provider isolation, device classification and ntfy response handling. Tests use isolated data. Fresh package startup, artwork and silent Windows notifications are checked before publication. The release's performed security checks are recorded in `SECURITY-AUDIT.md`.

Previous physical validation exists for Logitech PRO X 2 LIGHTSPEED and Pulsar Xlite V3. This record contains no personal inventories, serial numbers, device addresses, ntfy topics or exact historical battery readings. Hardware support that has not been physically tested is identified in `COMPATIBILITY.md`.

The application packages include only runtime files, user documentation, third-party notices and license-required corresponding source. Application tests and development artifacts remain in the source repository only. The smaller package needs .NET 10 Desktop Runtime x64; the portable package includes its own .NET runtime.

## Română

Suita Release trece **75 de teste automate** pentru prag/reactivare, încărcare, date lipsă/vechi, persistență, migrarea stării, parsarea protocoalelor, răspunsuri invalide, timeout, izolarea adaptoarelor, clasificarea dispozitivelor și răspunsurile ntfy. Testele folosesc date separate. Pornirea pachetelor, fotografiile și notificările Windows silențioase se verifică înainte de publicare. Verificările de securitate sunt consemnate în `SECURITY-AUDIT.md`.

Există validări fizice anterioare pentru Logitech PRO X 2 LIGHTSPEED și Pulsar Xlite V3. Documentul nu publică inventare personale, serii, adrese, canale ntfy sau procente istorice exacte. Suportul neverificat fizic este marcat în `COMPATIBILITY.md`.

Pachetele includ fișierele de rulare, documentația, licențele și sursele terțe obligatorii. Testele și artefactele de dezvoltare rămân numai în repository. Pachetul mic necesită .NET 10 Desktop Runtime x64; cel portabil include runtime-ul.
